Five minutes, no IT. This lets the app email the brief to you from an address in your own Resend account.

  1. Go to resend.com/signup and sign up with bstone@teamksi.com. Verify the email.
  2. In Resend, open API Keys and create a key named virginia with sending permission. Copy it once.
